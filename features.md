# Features

## 1. Start tracking an activity
Begin a timed session for an existing activity.

## 2. Stop tracking an activity
End the active session and record the elapsed time as a progress entry.

## 3. View activity log
Print a dated list of all progress entries across activities, showing date, activity name, and duration.

## 4. View stats dashboard
Open a browser-based VegaLite calendar bubble chart for each activity.
Each activity gets its own chart: rows = days of the week (Mon–Sun), columns = weeks.
Each day is plotted as a circle; diameter represents total duration logged that day.
No data = no circle (empty space, not a dot).
